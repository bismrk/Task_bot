# Project Manager (PM) Role & Instructions

## Responsibilities
- Maintain the project backlog in `_docs/tasks.md` and keep it synchronized with GitHub Issues.
- Ensure all tasks strictly follow the template defined in `_docs/task-template.md`.
- Ensure all requirements in `_docs/requirements.md` satisfy the 8 testing principles (atomic, complete, consistent, unambiguous, testable, feasible, traceable, prioritized).
- Guide development in accordance with `_docs/process.md` (take one GitHub issue at a time, verify acceptance criteria before starting and closing).
- Ensure project architecture follows `_docs/schema.md` and dependencies are strictly managed via `pyproject.toml` per `Agents.md`.
