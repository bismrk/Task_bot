# Telegram Task Tracker Bot — Специфікація проєкту

## 1. Scope функціоналу

### Взаємодія в Telegram Chat
* **00:00 (Планування + хвости):** Бот показує невиконані задачі за сьогодні (вибір: перенести на завтра чи закрити) і просить надиктувати план на завтра.
* **Обробка ГС та тексту:** AI розпізнає аудіо/текст, витягує задачі, дедлайни, пріоритети та теги. Бот одразу надсилає список на підтвердження (`Зберегти` / `Виправити`). Додавати чи редагувати задачі можна протягом усього дня.
* **09:00 та нагадування:** Ранковий пуш із кнопкою Mini App + денні чек-іни в обрані години + нагадування по дедлайнах (дефолт: за 1 год і 10 хв, налаштовується).

### Telegram Mini App
* **Список на сьогодні:** Чекбокси із закресленням, теги, пріоритети, дедлайни, перемикач повторюваних задач (щодня / по днях тижня).
* **Звіти:** Календар (перегляд будь-якого дня) + дашборд (графіки продуктивності, розбивка по тегах, стріки).
* **Налаштування:** Часовий пояс (підтримка до ~20 юзерів), години чек-інів, інтервали дедлайнів.

## 2. Стек технологій
* **Bot:** `aiogram 3.x`
* **API (Етап 2+):** `FastAPI` (авторизація через Telegram `initData`)
* **БД:** `SQLAlchemy 2.0` (async) + `SQLite` (режим WAL, драйвер `aiosqlite`, легка міграція на `PostgreSQL`)
* **Планувальник (Етап 3):** `APScheduler` (з підтримкою часових поясів користувачів)
* **AI:** `google-genai` (`gemini-2.5-flash`, Structured Outputs)
* **Frontend (Етап 2+):** `React` + `Vite` + `Tailwind CSS` + `Recharts` + `shadcn/ui`
* **Керування проєктом & залежності:** `uv` (`pyproject.toml`)

---

## 3. Швидкий запуск Етапу 1 (`bot.py`)

1. Встанови залежності через `uv`:
```bash
uv sync
```

2. Створи файл `.env` поруч із `bot.py` (за шаблоном `.env.example`):
```env
BOT_TOKEN=твій_токен_від_BotFather
GEMINI_API_KEY=твій_ключ_від_Google_AI_Studio
DATABASE_URL=sqlite+aiosqlite:///tasks.db
```

3. Запусти бота:
```bash
uv run python bot.py
```
